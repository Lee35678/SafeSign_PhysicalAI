## 1. 문제 정의

### 1-1. 현장의 문제

| 문제 | 근거 |
| --- | --- |
| **신호는 법으로 정한 안전 수단이다** | 양중기(크레인 등)를 쓰는 작업은 사업주가 신호방법을 정해 신호하게 하고, 운전자와 근로자는 그 신호를 따라야 한다(산업안전보건기준에 관한 규칙 제40조). 타워크레인 신호업무는 특별교육 대상이고 교육 내용에 "신호방법 및 요령"이 있다(산업안전보건법 시행규칙 별표 5, 39번) |
| **신호가 어긋나면 사고가 난다** | 타워크레인 양중작업 재해 343건 중 45건(13.0%)이 신호체계 미준수(신호방법 미숙지·신호 순서 미준수·신호내용 착각 등)에서 생겼다(임현무·김승호, 안전문화연구 18호, 2022, 원출처 안전보건공단). 이동식 크레인 사망재해 연구도 "운전자와 주변 작업자 간의 신호소통상에 의한 사고"를 주요 요인으로 꼽았다(신운철 외, 산업안전보건연구원, 2014). 현장마다 신호 용어를 따로 정해 쓰고, 현장실습 없이 투입돼 운전원과 신호가 맞지 않는다는 지적도 있다(임현무·김승호, 2022) |
| **크레인 사고는 지금도 사망으로 이어진다** | 2023년 근로감독관 조사 사망재해 564명 중 크레인류(크레인·타워크레인·이동식크레인)가 기인물인 사망은 23명(4.1%)이다(고용노동부, 「2023 산업재해 현황분석」 — 신호 원인은 따로 세지 않음). 2020년 아산 이동식 크레인 사망 사고에서는 "별도로 정한 기준없이 통상적인 방법으로 신호를 주고 받"은 것(신호체계 미수립)이 원인 중 하나로 지적됐다(안전보건공단 중대재해 사례) |
| **지금 교육은 이론 위주라 실제로 할 수 있는지 확인하지 못한다** | 국내 신호수는 자격증 없이 8시간 특별교육만 받으면 되고 자격 갱신도 없다. 교육은 이론 위주이고 실습·실기 평가가 없다는 지적이 있다(임현무·김승호, 2022 — 미국·영국·일본은 실기시험으로 검증). 그래서 영상·인쇄물 교육으로는 교육자가 학습자의 습득 정도를, 학습자가 자기 수준을 객관적으로 판단할 수단이 없다고 보았다(팀 문제 정의) |

> **인용 범위** — 타워크레인 논문의 결론은 타워크레인 수신호를 무선 신호로 바꾸자는 것이라, 여기서는 **신호수 교육 체계의 문제** 근거로만 쓴다.
> 이 키트의 수신호 7종 중 크레인 표준 기반 5종은 크레인작업표준신호지침(팔 동작)을 손 모양으로 **재해석한 시안**이다([02 §4-1](02_설계문서.md)).

### 1-2. 사용자와 풀어야 할 문제

| 사용자 | 문제 |
| --- | --- |
| 신입·현장 작업자 | 수신호를 **본 적이 있는지**와 **실제로 할 수 있는지**를 구분해 확인할 방법이 없다 |
| 안전 교육자 | 누가 어떤 수신호에 약한지 숫자로 알 수 없다 |

### 1-3. 해결 방향

로봇 손(AI Hand)이 수신호를 **시범**하고, 학습자가 따라 하면 카메라가 손을 **판정**하고, 결과를 micro:bit O/X와 picar 주행·LED로 **몸으로 돌려주는** 체험·실습형 교육 키트를 만든다.
결과는 회원별·수신호별로 **기록**해 교육자가 볼 수 있게 한다. AI Hand는 시범 전용이라 판정 뒤에는 움직이지 않는다.

- 체험·실습형 교육의 근거: VR 체험교육 이수자 설문에서 이해도 평균이 기존 온라인 교육 4.09에서 4.58로(5점 척도), 만족도·종합 평가도 12% 안팎 높았다(배필균, 서울과학기술대 석사논문, 2024).
  단 시기·문항이 다른 설문의 평균 비교라 효과를 입증한 것은 아니고, 업종도 이차전지 제조업 1개사다.

### 1-4. 기대 효과 (가설 — 이번 프로젝트에서 재지 않음)

- 안전 수신호 습득 속도·정확도 향상
- 작업자 간 소통 오류와 안전사고 감소
- 학습자별 취약 수신호 파악과 보완 (합격/불합격 저장 기능은 구현 — [18](18_DB설계서.md))

> 이번에 잰 것은 **시스템 성능**(아래 §3의 숫자 목표)뿐이다. 학습 효과와 사고 감소는 향후 현장 시범 운영에서 같은 학습자의 교육 전·후 시험을 비교하거나, 기존 교육(영상·인쇄물) 집단과 비교해 검증한다.

### 2-2. 제외

| 제외 항목 | 이유 |
| --- | --- |
| 수신호 등록(새 수신호 실시간 추가) | 학습된 분류기(SVM)는 학습 때 정한 클래스만 예측해, 새 수신호를 넣으려면 재학습이 필요하다 |
| 연속 제스처·동작 추적, 전신 신호(표준의 팔 동작) | 정지 자세 판정만으로 교육 목적을 이룰 수 있고, 연속 동작은 데이터와 학습 비용이 크게 늘어난다 |
| 다중 사용자 동시 인식 | 교육장 키트는 학습자 1명 기준 |
| 악조건 인식(역광, 렌즈 이물질, 암실, 야간 조명, 장갑 착용) | 교육장 실내 고정 환경을 전제로 한다 |
| 음성 안내·음성 신호 | micro:bit의 BLE와 소리 기능을 함께 쓸 수 없다(펌웨어 패닉) — 소리 대신 LED로 알린다 |
| 모델 신규 학습(from scratch) | 사전학습 MediaPipe + 경량 분류기 재학습까지만 |
| picar 워치독 조종 모드 | 2026-09-30 회의에서 불채택, 향후 과제 |

### 2-3. 전제 조건

- AI Hand는 단순하고 명확한 **정적 손 모양**만 표현할 수 있다.
- 카메라는 Raspberry Pi Camera Module 3(CSI)이고, 랜드마크는 RPi5에서 MediaPipe로 계산한다.
- 시연·측정은 교육장 실내에서 RPi5 PLA 케이스·카메라 거치대를 설치하고 선풍기로 냉각한 상태로 한다(측정 조건과 같게 — [06 §1-1](06_테스트·평가리포트.md)).

## 3. 숫자로 정한 목표치

| 지표 | 목표 | 정의 · 측정 방법 | 목표값 근거 | 결과 ([06 §2-1](06_테스트·평가리포트.md)) |
| --- | --- | --- | --- | --- |
| 대상 수신호 | **7종** | 7종 + 확신 부족·7종 밖은 미판정. "기타(negative)"는 학습 클래스가 아니다 | 범위 결정(§2) | 7종 구현 |
| 정답률 | **≥ 92%** | 정답 판정 수 / 전체 시도 수 | 팀이 정한 목표 | **95.2%** (95% CI 91.5~97.4%) — 잠정 달성 |
| 오분류율 | **≤ 3%** | 다른 수신호로 잘못 판정한 수 / 전체 시도 수 | 팀이 정한 목표 | **0%** (95% 상한 1.8%) — 달성 |
| 미판정률 | **≤ 5%** | 미판정(τ 미달·7종 밖) 수 / 전체 시도 수 | 팀이 정한 목표 | **4.8%** (95% CI 2.6~8.5%) — 잠정 달성 |
| Macro F1 | **≥ 0.90** | 신호 7종 F1의 평균(negative 제외) | 팀이 정한 목표 | **0.974** — 달성 |
| 치명 오분류 | **0건** | "정지"를 다른 신호 6종으로 판정한 건수 | 팀이 정한 목표 | **0건** (정지 30시도, 95% 상한 11.4%) — 잠정 달성 |
| 판정 지연 (P95) | **≤ 1.0초** | 연속 판정을 확정한 마지막 프레임의 캡처 → 판정 | 응답시간 1초 한계 — 사용자의 생각 흐름이 끊기지 않는 한계(Nielsen, *Usability Engineering*, 1993) | **0.046초** (95% 상한 0.065초) — 달성 |
| 물리 피드백 지연 (P95) | **≤ 2.0초** | 판정 확정 → picar·micro:bit가 반응을 시작할 때까지(완료 시점은 함께 기록) | 팀이 정한 목표 | 반응 시작 **0.089초** (95% 상한 0.262초), 완료 1.089초(picar 주행 제외) — 달성 |

**정의와 측정 방법**

- 정답률 + 오분류율 + 미판정률 = 100%가 되도록 서로 겹치지 않게 정의했다. 지연은 평균이 아니라 P95(95번째로 느린 값)로 잰다.
- **판정 성능 5개는 오프라인**(학습에 쓰지 않은 팀원 3명 × 70시도 = 210시도, 2026-09-29 촬영), **지연 2개는 온라인**(모든 장치를 실물로 연결한 91시도, 2026-10-02)으로 쟀다. 측정 규칙은 [16 §5](16_통합테스트_KPI_CI.md).
- **"잠정 달성"**: 점추정은 목표 안이지만 95% 신뢰구간이 목표선에 걸친 것이다. 표본을 늘리면 구간이 좁아진다(치명 오분류 상한을 3% 아래로 내리려면 정지만 약 125시도).
- **판정 지연의 한계**: 기록값은 마지막 프레임 1장만 잰다. 손을 멈춘 뒤 장치가 반응하기 시작할 때까지는 240fps 슬로모션 7시도로 0.14~0.24초였다 — 1초 안이지만 0.1초 "즉각 반응"은 넘는다([06 §2-3](06_테스트·평가리포트.md)).
- **물리 피드백 기준**: 처음 정의(손 정지 → 가장 늦게 끝나는 장치까지)에는 picar 주행(약 2초 뒤 자동 정지)이 들어가 구조상 2.0초를 넘는다. 그래서 2026-09-30 회의에서 "반응 시작"으로 판정하고 완료를 함께 적기로 했다.
- **목표값 근거**: 외부 근거가 있는 것은 판정 지연 1.0초뿐이다. 나머지는 계획 단계에서 팀이 정한 목표이며 외부 근거는 없다([proposals/참고자료 "KPI 목표값 근거"](proposals/참고자료.md)).
