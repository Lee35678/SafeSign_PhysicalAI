## 추진 배경과 목적

**현행 이슈**

- 다양한 분야의 산업 현장에서 작업자마다 안전 수신호에 대한 이해와 표현이 달라, 작업자 간 안전 수신호를 통한 의사 전달 시 소통 오류로 안전 사고를 초래하는 위험이 있음.
- 기존 교육 방식(교육물 시청, 인쇄물)은 교육자 입장에서 다수 학습자의 학습 정도를 객관적으로 판단하기 어렵고, 학습자 입장에서 본인의 이해 정도를 판단하기 어려움.

**추진 필요성**

- 시범·인식·평가 체계를 구축함으로써 체계적인 수신호 교육 진행 가능
- 로봇 손(AiHand)을 통한 반복 학습·피드백으로 상황에 맞는 수신호 수행 능력 향상
- 정량적 지표(정답률·응답시간 등)로 교육자가 학습자 이해 수준을 객관적으로 판단 가능

**기대 변화**

- 신입/현장 작업자의 안전 수신호 습득 속도 및 정확도 향상
- 작업자 간 소통 오류 감소로 안전 사고 감소
- 반복 학습을 통한 학습자별 취약 수신호 파악 및 보완
- 정량적 지표를 통한 교육 내용 보완

**“피지컬 AI”인 이유**: 인식 결과가 물리적 액추에이터(AI Hand, micro:bit, picar)로 되먹임되는 닫힌 제어 루프 구조 → 상세 구조는 설계 문서 참고.

## 목표와 KPI

**정량 목표**

| 지표 | 목표값 | 정의 / 측정 방법 |
| --- | --- | --- |
| 대상 수신호 종류 | **7종** (+ τ 미달 시 미판정) | 7종 목록은 02_설계문서_v2 §4·§4-1 · 04_데이터셋명세서_v2 §1 참고. **“기타(negative)”는 학습 클래스가 아니다** — 손은 있으나 7종이 아닌 자세는 종류가 무한해 하나의 클래스로 학습할 수 없고, 실제로 공개 데이터의 negative는 0건이었다. 신뢰도 임계값 τ 미달을 미판정으로 처리하고 그 출력 라벨로만 `negative`를 쓴다 (2026-09-21 회의 안건 2 A, 05_모델카드_v3 §8-1) |
| 정답률 (Accuracy) | ≥ 92% | 정답 판정 수 / 전체 시도 수 × 100 |
| 오분류율 | ≤ 3% | 다른 수신호로 잘못 판정한 수 / 전체 시도 수 × 100 |
| 미판정률 (Reject) | ≤ 5% | 신뢰도 임계값 미달로 판정 보류한 수 / 전체 시도 수 × 100 |
| Macro F1 | ≥ 0.90 | 클래스 불균형 방어 |
| 치명 오분류 | 0건 | “정지” 신호를 다른 신호로 판정한 건수 (별도 집계) |
| 판정 지연 (P95) | ≤ 1.0초 | 손 정지 시점 → 시스템 판정 확정까지 |
| 물리 피드백 지연 (P95) | ≤ 2.0초 | 손 정지 시점 → AI Hand + picar + micro:bit 중 가장 늦게 완료되는 시점까지 |

> 정답률+오분류율+미판정률=100%가 되도록 배타적으로 재정의함. 지연 지표는 평균이 아닌 P95로 측정.
> 

**정성 목표**

- 비전공자 팀원도 기능 파트를 이해하고 발표에서 직접 설명 가능한 수준 도달
- 팀 전체가 “문제 정의 → 구현 → 평가” 흐름을 스스로 설명 가능
- 시도와 실패 과정을 구체적으로 기록하여 결과보고서에 반영
- 산업 현장 작업자 간 안전 수신호 소통 원활화
- 안전 교육자의 교육 부담 감소

## 범위

**포함 범위**

- 정적 안전 수신호 선정 및 AI Hand 로봇 손동작 설계
- picar를 이용한 수신호별 물리 동작(정지·서행·좌우회전·후진·주의 등) 출력 구현
- 시범 → 연습 → 평가 → 피드백의 4단계 학습 흐름 구현
- 오답 유형별 재시도 로직 및 학습 기록 기능
- 정량 지표 측정 및 로그 분석
- 일치율(유사도) 산출 및 0~100 점수 표시 (학습된 분류기 클래스 기준 템플릿과의 유사도)
- micro:bit 기반 물리 입출력 피드백
- 신분 확인 모듈 (QR/바코드 로그인, 직군별 커리큘럼 분기) — *부가 기능, W4 이후 여유 시*

**제외 범위**

- **수신호 등록(신규 수신호 실시간 추가) 기능** — 경량 분류기(SVM) 채택에 따른 결정. 규칙/유사도
  기반 시스템이었다면 재학습 없이 템플릿만 추가해도 즉시 인식이 가능했겠지만, 학습된 분류기는 학습
  시점에 고정된 클래스만 예측하므로 신규 클래스 추가에는 재학습이 필요함 — 이번 범위에서 제외
  (03_인터페이스계약서_v2 §6, 05_모델카드_v3 §5-2 참고)
- 연속 제스처·동작 추적 (하드웨어 제약)
- 음성 안내 등 부가 기능
- 다중 객체/다중 사용자 동시 인식
- 손만 구분하여 인식
- 악조건(역광, 렌즈 이물질, 암실, 야간 조명, 장갑 착용)에서 인식
- 전신 신호, 음성 신호 인식
- 모델 신규 학습(from scratch) — 사전학습 가중치 + 경량 분류기 재학습까지만

**전제조건**

- AiHand는 단순하고 명확한 정적 손 모양만 인식·표현 가능
- 미션맵 재료는 09.18까지 신청 완료 (팀당 최대 30만원, 초과분 미지원)
- 팀원 4명의 가용 시간이 주 2회 정기 회의 기준으로 확보됨을 전제
- W3(09.21~09.27)에 추석 연휴 포함되어 실작업일 감소
- 카메라는 랜드마크 좌표를 호스트로 넘길 수 있는 장치여야 함 (리스크 레지스터 참고)
