# 촬영 안내 — KPI 측정용 데이터

받는 사람: 촬영을 맡아주신 두 분 · 요청: 이동혁(vision) · 2026-09-21
소요 시간: **1인당 20~30분** (설치 5분 + 촬영 15~25분)

---

## 왜 찍나요

지금 분류기는 인터넷 공개 데이터 27,735건으로 학습돼 있는데, **촬영자가 누구인지 기록이 없습니다.**
그래서 거기서 나온 점수(77.57%)는 "처음 보는 사람에게도 통한다"는 증거가 못 됩니다.

계획서의 KPI 5개 항목 — 정답률 ≥92%, 오분류율 ≤3%, 미판정률 ≤5%, Macro F1 ≥0.90, 치명 오분류 0건 —
은 **두 분이 찍어주시는 이 데이터로만 측정할 수 있습니다.** 이게 유일한 경로입니다.

> **사진은 저장되지 않습니다.** 웹캠 화면에서 손 관절 21개의 좌표(숫자)만 뽑아 JSON으로 남깁니다.
> 얼굴이나 배경은 파일에 들어가지 않습니다.

## 1. 준비 (5분, 한 번만)

```bash
git pull
cd services/vision
pip install -r requirements-dev.txt
```

카메라가 여러 개면 몇 번인지 먼저 확인하세요.

```bash
python scripts/webcam_check.py --list-cameras
```

## 2. 촬영 (15~25분)

```bash
python scripts/record_dataset.py --subject-id ext01
```

**`--subject-id`는 사람마다 다르게 주세요** (`ext01`, `ext02` …). 이게 겹치면 파일이 덮어써지고,
"사람 단위로 나눠서 평가한다"는 목적 자체가 깨집니다. 실명 대신 익명 ID로 주세요.

카메라 번호가 0이 아니면 `--camera 1` 처럼 붙이면 됩니다.

### 화면 보는 법

창 위쪽에 이렇게 뜹니다.

```
정지   ●●●●●
다섯 손가락 모두 펴기  /  손바닥을 카메라에 정면으로
테이크 3/10   저장 6건   [대기]
```

- `●●●●●` = 엄지·검지·중지·약지·소지 순서. ● 펴기 / ○ 접기
- 수신호를 몰라도 **화면에 나온 그대로** 하시면 됩니다
- 아래 줄의 "정면 / 좌기울임 / 우기울임"은 **손목을 그 방향으로 기울여 달라**는 뜻입니다.
  테이크마다 바뀝니다

### 조작

| 키 | 동작 |
|---|---|
| **SPACE** | 촬영 (2초 카운트다운 후 자동 캡처) |
| **U** | 직전 테이크 취소 (잘못 찍었을 때) |
| **N** | 이 클래스 건너뛰기 |
| **Q** 또는 ESC | 종료 (지금까지 찍은 건 남습니다) |

손이 화면에 안 잡히면 `[손 없음]`으로 표시되고 저장되지 않으니, 그 상태에서 SPACE를 눌러도 괜찮습니다.

## 3. 촬영 수칙 — 이게 제일 중요합니다

### ① 테이크마다 손을 완전히 내렸다가 다시 드세요

가장 중요한 항목입니다. 자세를 고정한 채 연달아 찍으면 **사실상 같은 사진 여러 장**이 되어,
데이터를 아무리 많이 모아도 쓸모가 없어집니다.

> 공개 데이터에서 실제로 이 문제를 겪었습니다. 같은 원본에서 나온 사진들이 섞여 있어서
> 정답률이 98.81%로 나왔는데, 제대로 나눠서 재니 **77.57%** 였습니다.
> 우리가 직접 찍는 데이터에서 같은 함정을 만들면 안 됩니다.

### ② 카메라와의 거리를 테이크마다 조금씩 바꿔주세요

가깝게, 멀게, 화면 왼쪽, 오른쪽 — 조금씩 다르면 됩니다.

### ③ 두 분이 서로 다른 장소·조명에서 찍어주세요

같은 책상 같은 조명에서 둘 다 찍으면 한 사람이 찍은 것과 큰 차이가 없습니다.

### ④ 일부러 어긋나게 하지 마세요

"틀린 데이터도 필요하지 않나?" 싶으실 수 있는데, **지금은 필요 없습니다.**
안내대로 자연스럽게 하시면 손가락 벌어짐·각도가 매번 조금씩 달라지는데, 그 변동이 바로 필요한
것입니다. 일부러 만든 어긋난 자세는 "이게 정답인가 오답인가"를 우리가 아직 정하지 않아서
쓸 수가 없습니다.

## 4. 무엇을 얼마나

| 순서 | 명령 | 분량 | 목적 |
|---|---|---|---|
| **1** | `python scripts/record_dataset.py --subject-id ext01` | 7종 × 10회 (기본값) | **KPI 측정 본체 — 이것만 해주셔도 됩니다** |
| 2 | `python scripts/record_dataset.py --subject-id ext01 --ambiguous --takes 8` | 8회 | 7종 중 아무것도 아닌 자세. 시스템이 "모르겠다"고 하는지 확인용 |
| 3 (선택) | `python scripts/record_dataset.py --subject-id ext01 --variant borderline --takes 2` | 7종 × 2회 | 일부러 살짝 어긋난 자세. 채점 기준 정할 때 참고용 |

**1번이 필수이고, 2번까지 해주시면 충분합니다.** 3번은 여유 있으면.

2번(`--ambiguous`)은 화면에 `?????`가 뜨는데, **매번 다른 자세**로 해주세요 —
반쯤 편 손, 가위, 손날, 손가락 3개 펴기 등 7종에 없는 아무 모양이나요.

## 5. 끝나면

파일은 여기 쌓입니다.

```
services/data/datasets/self_recorded/{클래스}/{subject_id}_{클래스}_t01_f1.json
```

용량이 작아서(1인당 100KB 안팎) 그대로 커밋해주시면 됩니다.

```bash
git add services/data/datasets/self_recorded
git commit -m "KPI 측정용 자체 촬영 데이터 (ext01)"
git push
```

푸시하셨으면 **저에게 알려주세요.** 바로 평가 돌려서 KPI 실측치를 내겠습니다.

## 자주 나올 만한 문제

| 증상 | 해결 |
|---|---|
| `카메라 0번을 열 수 없습니다` | 다른 앱(줌·팀즈 등)이 점유 중인지 확인. `--list-cameras`로 번호 확인 후 `--camera 1` |
| 클래스명이 영어로 나옴 | 한글 폰트를 못 찾은 것. 판정에는 영향 없으니 그대로 진행하셔도 됩니다 |
| `[손 없음]`만 계속 뜸 | 손이 화면 안에 다 들어오게, 조명을 밝게. 배경이 손과 비슷한 색이면 바꿔보세요 |
| 중간에 끊고 싶음 | Q로 종료. 다시 실행하면 이어서 하실 수 있는데, **같은 `--subject-id`를 쓰면 앞 테이크를 덮어씁니다.** `--classes 후진,주의` 처럼 남은 클래스만 지정해주세요 |
| `pip install`이 오래 걸림 | mediapipe가 커서 그렇습니다. 5분 정도 걸릴 수 있습니다 |

막히면 아무 때나 물어보세요. — 이동혁
