# Raspbot_pinmap

> **출처·검증**: 제작사(Yahboom) 제공 SD 이미지 `Raspbot_rpi4B.img` 내부의 교보재 코드
> (`2.硬件控制课程/` 노트북, `raspbot/YB_Pcb_Car.py`)와 대조해 **2026-09-22 전량 재확인**.
> 분석 경위와 근거는 `11_하드웨어설계서_v1.md` §5.5.
>
> 🔴 **제작사 코드는 `GPIO.setmode(GPIO.BOARD)`(물리 핀 번호)를 쓴다.** 우리 코드
> (`services/picar`)는 **BCM 기준**이므로, 제작사 예제의 상수를 그대로 옮기면 전혀 다른 핀을 잡는다.
> 아래 표에서 반드시 **BCM 열**을 볼 것.

**I2C 코프로세서 상세** (`YB_Pcb_Car.py` 확증, 2026-09-22)

| 항목 | 값 |
| --- | --- |
| 버스 | `/dev/i2c-1` (SCL=BCM3 / SDA=BCM2) |
| 슬레이브 주소 | **`0x16`** — Raspbot V2는 `0x2B`. 실물에서 `i2cdetect -y 1`로 확인하고, 다르면 `RASPBOT_I2C_ADDR` 환경변수로 덮어쓴다 |
| 레지스터 `0x01` | 모터 — `[좌_방향, 좌_속도, 우_방향, 우_속도]` (방향 0=후진/1=전진, 속도 0~255) |
| 레지스터 `0x02` | 정지 — 단일 바이트 `0x00` |
| 레지스터 `0x03` | 서보 — `[서보ID, 각도 0~180]` (S1=팬, S2=틸트. 주행에는 미사용) |

## 우리가 추가한 배선 — 외부 LED 3핀

내장 LED는 적색·청색 1개씩뿐이라 설계가 요구하는 **적색 2 + 황색 2**를 채울 수 없다.
외부 LED 4개를 아래 3핀으로 구동한다 (`11_하드웨어설계서_v1.md` §5.3, 2026-09-21 확정).

| 채널 | BOARD 핀 | BCM | 연결 | 개별 제어 |
| --- | --- | --- | --- | --- |
| `led_red` | 33 | **13** | 적색 2개 **병렬** | 불필요 — 항상 양쪽 동조 |
| `led_yellow_left` | 29 | **5** | 황색 1개 | 필수 — 좌회전 시 단독 점멸 |
| `led_yellow_right` | 31 | **6** | 황색 1개 | 필수 — 우회전 시 단독 점멸 |

- **내장 적색(BCM21)은 쓰지 않는다** — 직렬저항 값을 알 수 없어 외부 2개를 더 물리면 핀 전류
  한도(기본 8mA)를 넘길 위험이 있다.
- LED마다 **개별 330Ω 직렬저항**을 달 것 (공통 저항 금지 — 밝기 불균일·전류 쏠림).
- 이 3핀은 `services/picar/src/controller.py`의 `PIN_MAP`과 같은 값이며,
  `tests/test_controller.py`가 위 점유 표와의 충돌을 **자동 검사**한다.

## 요약 — picar 작업 시 중요한 핀

### 🟢 완전히 자유로운 핀

`BCM 5, 6, 13, 19, 26`

이 중 **5·6·13은 위 외부 LED에 이미 배정**됐으므로, 추가 배선에 실제로 남는 것은 **BCM 19, 26** 뿐이다.
`BCM 7/8/11`(SPI0 CE1/CE0/SCLK), `14/15`(UART), `18`(PWM0/PCM)은 기능 겸용이라 권장하지 않는다.

### ⚠️ 주의가 필요한 점유 핀

| 핀 | 문제 |
| --- | --- |
| BCM 9, 10 | 적외선 회피 센서가 **SPI0의 MISO/MOSI**를 점유한다. 제작사 이미지는 `dtparam=spi=on` 상태라 SPI 주변장치와 동시 사용이 불가능하다 (우리는 회피 센서를 안 쓰므로 실사용 영향 없음) |
| BCM 16 | 커널 `gpio-ir` 드라이버 + `lircd`가 잡는데, 교보재 코드는 같은 핀을 직접 비트뱅잉으로 폴링한다 — **이중 점유** |
| BCM 2, 3 | I2C. 모터·서보 구동의 유일한 경로이므로 절대 다른 용도로 쓰지 말 것 |

### 이 제품이 실제로 쓰는 것

Raspbot의 트래킹·초음파·적외선 회피·부저·IR 수신은 **전부 사용하지 않는다.**
쓰는 것은 **모터(I2C)와 외부 LED 3핀**뿐이다.
