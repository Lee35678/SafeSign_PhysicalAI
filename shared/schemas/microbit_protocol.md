# micro:bit 시리얼 프로토콜 (초안)

원본: `document/03_인터페이스계약서_v1.md` §5-2. JSON이 아닌 일반 텍스트 프로토콜이라 별도 파일로 관리합니다.
실제 값은 actuation 담당(송승호)이 micro:bit 코드와 함께 실측 후 이 파일과 계약서 문서를 동시에 갱신하세요.

## RPi/web -> micro:bit (LED 매트릭스 표시 지시)

```
RESULT:OK:87\n
```

- `RESULT` 고정 문자열
- `OK|NG` 정오답
- `87` match_score (0~100 정수)
- 종료 문자 `\n`

## micro:bit -> RPi/web (버튼 입력)

```
BTN:A\n
BTN:B\n
BTN:AB\n
```

분야 선택 버튼 순환(산업→건설→농업→수중)에도 동일 채널 사용 예정 — 분야 ID 전송 포맷은
⚠️ 미확정 (시스템_구성도_초안.md §5 참고). 확정되는 대로 여기에 `FIELD:<id>\n` 형태로 추가.

## 미확정 항목 (실측 후 채우기)

- 필드 구분자, 종료 문자, 파싱 실패 시 재전송 여부
- 통신 두절 시 폴백: 화면 폴백 UI로 정오답 표시 (web 서비스에서 처리, 03_인터페이스계약서_v1 §7)
