## 디렉터리

```
datasets/
├── raw/{class_name}/                              # 자체 촬영 원본 — git 제외
└── processed/{class_name}/{subject_id}_{index}.json   # 랜드마크 — git 제외
models/hand_landmarker.task                        # MediaPipe 모델 (7.8MB, 자동 다운로드) — git 제외
```

수집한 원본 사진은 저장소 밖에 두고, 변환 시 `--src`로 경로를 넘깁니다.

- `src/build_dataset.py` — 사진 → 랜드마크 JSON 변환 **(신규)**
- `src/collect.py` — 카메라 촬영 → 랜드마크 JSON (미구현)
- `src/init_db.py` — 템플릿 DB(SQLite) 스키마 생성 (완성)
- `src/seed_templates.py` — 템플릿을 DB에 시드 (미구현)

### 출력 JSON 형식

`services/vision`의 학습 노트북·`make_dummy_dataset.py`와 동일한 형식입니다. 이동혁님의
`normalize.py`에 그대로 물려 63차원 특징벡터가 나오는 것을 확인했습니다.

```json
{
  "class_name": "정지", "subject_id": "public", "handedness": "Right",
  "landmarks": [{"id": 0, "x": -0.01563, "y": 0.093545, "z": 0.001524}, "... 21개"],
  "source": {"folder": "정지", "file": "hand5_0_bot_seg_1.jpeg"}
}
```

좌표는 소수점 6자리로 반올림합니다 — world landmarks는 미터 단위(손 전체 약 0.1m)라 6자리면
1마이크로미터 정밀도이고, 원본 정밀도를 다 쓰면 파일만 2배가 됩니다. 1건당 약 1.4KB입니다.

## 로컬 실행

### 사진 → 랜드마크 변환 (호스트에서 직접 실행)

```bash
pip install mediapipe opencv-python numpy
```

> ⚠️ `requirements.txt`의 `mediapipe==0.10.14`는 Python 3.12까지만 지원합니다. Python 3.13
> 이상에서는 위처럼 버전 지정 없이 설치하세요(1.0.1). Docker(`python:3.11-slim`)에서는
> `requirements.txt` 그대로 동작합니다.

```bash
# 1) 사전 점검 — 사진에서 손을 얼마나 찾아내는지 먼저 확인 (저장 안 함)
python src/build_dataset.py --src <원본폴더> --probe 40

# 2) 전체 변환
python src/build_dataset.py --src <원본폴더> --clean

# 일부 클래스만 / 클래스당 장수 상한
python src/build_dataset.py --src <원본폴더> --classes 정지 서행 --per-class 500
```

**1) 을 건너뛰지 마세요.** 검출률이 낮으면 원본이 아무리 많아도 확보 장수가 300장
(`04_데이터셋명세서_v2.md` §2)에 못 미칩니다. 실행이 끝나면 클래스별 확보 장수와 충족 여부를
표로 출력합니다.

### 템플릿 DB (docker-compose tools 프로필)

DB 경로(`/data/db/signdb.sqlite3`)가 compose 볼륨 기준이므로 **반드시 tools 프로필로** 실행합니다.

```bash
docker compose --profile tools run --rm data-tools python src/init_db.py
docker compose --profile tools run --rm data-tools python src/seed_templates.py
```

## 실행 시 걸리는 함정 두 가지

- **한글 경로**: MediaPipe 네이티브 코드와 `cv2.imread`/`cv2.imwrite`는 한글이 들어간 경로의
  파일을 열지 못합니다. Windows 사용자명이 한글이면 반드시 모델을 읽어 `model_asset_buffer`로
  넘기고, 이미지는 `np.fromfile` + `cv2.imdecode`로 읽어야 합니다. **다른 서비스에서 같은
  증상이 나오면 동일하게 처리하세요.**
- **MediaPipe 버전**: 이 스크립트는 1.0.1(Python 3.13)로 검증했고 `services/vision`은
  0.10.14로 고정돼 있습니다. 모델 번들은 같은 파일이라 결과가 거의 같지만, 학습과 추론의
  전처리가 어긋나면 정확도가 조용히 떨어지므로(`MODEL_TRAINING.md` §7) 팀 전체가 같은 버전을
  쓰는 것이 안전합니다.
