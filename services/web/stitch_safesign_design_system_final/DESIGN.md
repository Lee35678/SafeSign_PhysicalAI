## Brand & Style

This design system occupies the convergence of high-velocity AI developer infrastructure and mission-critical industrial safety compliance. It bridges the precision, speed, and understated polish of modern toolchains (e.g., Linear, Vercel) with the uncompromising reliability and spatial awareness required by physical hardware, plant telemetry, and enterprise-grade autonomous systems.

### Aesthetic Foundation
- **Modern Minimalist-Technical & Refined Glassmorphism:** Deep obsidian foundation layers with translucent micro-surfaces, subtle linear gradations, and razor-sharp borders.
- **HUD & Telemetry Precision:** High information density achieved without cognitive fatigue through strict structural hierarchy, optical alignment, and deliberate accent glows.
- **Industrial Readiness:** Contrast ratios consistently exceed WCAG AAA standards on core metrics. Critical states employ vivid amber cautions and electric violet operational markers, treating warning systems with physical-grade gravitas.

## Colors

The palette operates in strict dark mode, anchored by deep, obsidian space and accented by focused photonic energy.

### Core Swatches
- **Primary (`#6366F1` - Electric Indigo):** Drives primary intent, active neural threads, computing cluster selections, and directional focus.
- **Secondary (`#F59E0B` - Industrial Amber):** Critical safety warnings, hazardous machine interventions, telemetry anomalies, and live threshold overflows.
- **Tertiary (`#10B981` - Synthetic Emerald):** Nominal hardware states, verified compliance gates, and calibrated autonomous models.
- **Neutral Core (`#090A0F` - Deep Obsidian):** Deep void substrate grounding the canvas.

### Surface Tiers & Overlays
- **Canvas Base:** `#090A0F`
- **Surface Elevation 1 (Card/Container):** `#12151E`
- **Surface Elevation 2 (Elevated Flyouts/Modals):** `#181C28`
- **Glass Panel Fill:** `rgba(18, 21, 30, 0.72)` with `backdrop-filter: blur(16px)`
- **Structural Border (Subtle):** `rgba(255, 255, 255, 0.08)`
- **Active Structural Border (Indigo Glow):** `rgba(99, 102, 241, 0.45)` with `box-shadow: 0 0 12px rgba(99, 102, 241, 0.2)`
- **Warning Structural Border (Amber Flash):** `rgba(245, 158, 11, 0.5)` with `box-shadow: 0 0 14px rgba(245, 158, 11, 0.25)`

### Functional Text Hierarchy
- **Primary Text:** `#F8FAFC` (Slate 50)
- **Secondary / Supporting Text:** `#94A3B8` (Slate 400)
- **Tertiary / Telemetry Grid Labels:** `#475569` (Slate 630)

## Typography

The type system balances systematic engineering clarity with ergonomic readability.

- **Primary Interface Type (`Geist`):** Delivers clean geometry, balanced proportions, and dense UI optimization across desktop telemetry dashboards and dense administrative panels.
- **Code & Telemetry Engine (`JetBrains Mono`):** Dedicated to all numerical readout units, system logs, runtime statuses, coordinate values, and tabular analytics matrices. Ensures zero jitter during live data streams through tabular numerical sizing.

### Typographic Rules
- Numeric metrics and counters must always deploy `JetBrains Mono` with tabular lining figures (`font-variant-numeric: tabular-nums`).
- All uppercase labels (`telemetry-xs`, `label-mono-sm`) demand a positive tracking range (`0.02em` to `0.05em`) to retain visual air within dark backgrounds.

## Layout & Spacing

The structural framework is built on an incremental 4px spatial baseline, using 12-column fluid grid constraints on desktop viewports and continuous auto-stack systems for constrained layouts.

### Screen Adaptations
- **Desktop (>= 1280px):** 12-column dynamic grid, `gutter-desktop` (24px), outer margins set to `margin-desktop` (40px). Max page containment layer set to 1600px for hyper-dense dashboard layouts.
- **Tablet (768px - 1279px):** 8-column layout, `gutter` (16px), outer margins set to `margin-tablet` (24px). Dual-pane configurations collapse secondary detail drawers into slide-over panels.
- **Mobile (< 768px):** 4-column flow, single column execution for industrial metric cards, `gutter` (16px), canvas margins at `margin` (16px). High-density metric grids transition into swipeable horizontal rails or fixed vertically indexed cards.

## Elevation & Depth

Spatial layering relies on translucent illumination and boundary definitions over physical drop shadows. Dark-mode depth is expressed through illumination shifts rather than black drop-castings.

### Depth Hierarchy
- **Level 0 (Canvas Void):** `#090A0F`, solid, inactive background plane.
- **Level 1 (Docked Containers & Workspaces):** Surface `#12151E` layered with a crisp outline: `border: 1px solid rgba(255, 255, 255, 0.07)`.
- **Level 2 (Active Cards & Tooling Modules):** Glass surface fill `rgba(18, 21, 30, 0.8)` backed by `backdrop-filter: blur(12px)`. Internal top border highlight `inset 0 1px 0 0 rgba(255, 255, 255, 0.08)`.
- **Level 3 (Popovers, Flyouts, Contextual HUDs):** High surface `#181C28` with combined subtle ambient spread: `box-shadow: 0 20px 32px -8px rgba(0, 0, 0, 0.7), 0 0 0 1px rgba(255, 255, 255, 0.12)`.
- **Level 4 (Active Diagnostic Focus & Critical Overrides):** Outer perimeter glow driven by contextual system states:
  - System Active: `0 0 0 1px #6366F1, 0 0 24px -4px rgba(99, 102, 241, 0.35)`
  - Critical Alarm / Safety Halt: `0 0 0 1px #F59E0B, 0 0 24px -4px rgba(245, 158, 11, 0.4)`

## Shapes

The design system maintains a calibrated "Soft" architectural geometry (`roundedness: 1`), conveying technical engineering precision without the aggressive harshness of total 0-radius brutalism.

### Geometric Conventions
- **Standard UI Panels, Form Modules, Containers:** 4px (`0.25rem`) border-radius.
- **Cards, Popovers, HUD Telemetry Boxes:** 8px (`0.5rem`) border-radius (`rounded-lg`).
- **Modals & Overarching Framework Shells:** 12px (`0.75rem`) border-radius (`rounded-xl`).
- **Telemetry Chips, Hardware Indicators, Micro-Badges:** Strict full-pill radius (`9999px`) to create immediate semantic contrast against the surrounding structural, squared grid.

## Components

### Buttons
- **Primary Action:** Solid `#6366F1` background, `#FFFFFF` text, 4px radius, `font-family: Geist`, 13px weight 500. Box shadow: `inset 0 1px 0 rgba(255, 255, 255, 0.2), 0 1px 2px rgba(0, 0, 0, 0.4)`. Hover state triggers localized luminance transition to `#4F46E5`.
- **Safety Interlock (Destructive/E-Stop):** `#F59E0B` outline with translucent amber interior `rgba(245, 158, 11, 0.1)`. Active pulse state utilizing amber edge glow.
- **Secondary / Ghost:** Transparent background, `1px solid rgba(255, 255, 255, 0.1)`, Slate 300 text. Hover adds surface fill `rgba(255, 255, 255, 0.04)` and brightens border to `rgba(255, 255, 255, 0.2)`.

### Chips & Hardware Status Indicators
- **Telemetry Pill Badges:** Full-pill structure (`border-radius: 9999px`), padding `2px 8px`, `JetBrains Mono` at 11px uppercase.
- **Live State Variant:** Contains a leading 6px circular LED indicator dot. Pulsing ambient ring animation applied for live data streaming or active model evaluation.
- **Caution State:** Border `rgba(245, 158, 11, 0.3)`, fill `rgba(245, 158, 11, 0.08)`, text `#FBBF24`.

### Lists & Tabular Data
- Zero-gap rows separated by `1px solid rgba(255, 255, 255, 0.04)`.
- Alternating or dynamic row hover activating subtle fill `rgba(255, 255, 255, 0.02)`.
- Metrics columns utilize `JetBrains Mono` and align strictly right; categorical labels align left.

### Form Inputs
- **Text & Numerical Fields:** Height 36px, background `#0D1017`, border `1px solid rgba(255, 255, 255, 0.1)`, 4px radius. Typeface is `Geist` for descriptions and `JetBrains Mono` for programmatic inputs and variables.
- **Focus Mode:** Border transition to `#6366F1` with an immediate glow halo: `box-shadow: 0 0 0 1px #6366F1, 0 0 8px rgba(99, 102, 241, 0.25)`.

### Checkboxes & Segmented Toggles
- **Checkboxes:** Squared 14px boxes with 2px corner radius. Inactive: `#12151E` with subtle white border. Active: filled with `#6366F1` displaying high-contrast white vector glyph.
- **Segmented Control Hubs:** Enclosed dark rail (`#090A0F`) housing floating active segment chip styled with `#1E2333` fill, fine border, and crisp typography.

### Cards & Telemetry Nodes
- Base background `#12151E` with a hairline top gradient border imitating overhead light catch.
- Integrated HUD header slots containing node addresses, uptime logs, and safety integrity level (SIL) badges.
