# micro:bit v2 ↔ StartbitV2 확장보드 통합 핀맵

> 출처: [Hiwonder/StartbitV2](https://github.com/Hiwonder/StartbitV2) 저장소의 `StartbitV2.ts`, `StartbitRGBLight.ts` 코드 분석 + micro:bit v2 표준 엣지 커넥터 핀 기능

## 전체 핀맵

| 핀 번호 | micro:bit v2 기본 기능 | StartbitV2 확장보드 용도 | 확장보드 번호 | 상태 |
|---|---|---|---|---|
| **P0** | GPIO, 아날로그 가능 | 코드상 미사용 | — | 🟢 여유 |
| **P1** | GPIO, 아날로그 가능 | Port1 신호: 터치센서 / 장애물회피 / 라인트레이서 / 조도센서 / 팬 / 디지털튜브(DIO) / 초음파(Trig) 겸용, 라이트벨트 Port1 데이터 | 10 | 🔴 사용중(공용) |
| **P2** | GPIO, 아날로그 가능 | Port1 신호: 위와 동일 그룹(2번째 신호선), 초음파(Echo) / 디지털튜브(CLK) | 10 | 🔴 사용중(공용) |
| **P3** | GPIO, 아날로그 가능 (v1은 LED col1, v2는 미사용) | 코드상 미사용 | — | 🟢 여유 |
| **P4** | GPIO, 아날로그 가능 (v1은 LED col2, v2는 미사용) | 코드상 미사용 | — | 🟢 여유 |
| **P5** | 버튼 A (겸용 GPIO) | 코드상 미사용 | — | 🟢 여유 (버튼A와 겸용 주의) |
| **P6** | GPIO (v1은 LED col9, v2는 미사용) | 코드상 미사용 | — | 🟢 여유 |
| **P7** | GPIO (v1은 LED col8, v2는 미사용) | 코드상 미사용 | — | 🟢 여유 |
| **P8** | GPIO, 범용 | **서보 컨트롤러(STC8G2K64S4) 시리얼 RX** | 2 | 🔴 사용중 (절대 건드리면 안 됨) |
| **P9** | GPIO (v1은 LED col7, v2는 미사용) | 코드상 미사용 | — | 🟢 여유 |
| **P10** | GPIO, 아날로그 가능 (v1은 LED col3, v2는 미사용) | 코드상 미사용 | — | 🟢 여유 |
| **P11** | 버튼 B (겸용 GPIO) | 코드상 미사용 | — | 🟢 여유 (버튼B와 겸용 주의) |
| **P12** | GPIO, 범용 | **서보 컨트롤러(STC8G2K64S4) 시리얼 TX** | 2 | 🔴 사용중 (절대 건드리면 안 됨) |
| **P13** | GPIO (SPI MOSI 겸용) | Port2 신호: 터치센서 / 장애물회피 / 팬 / 초음파(Echo) / 디지털튜브(DIO), 라이트벨트 Port2 데이터 | 10 | 🔴 사용중(공용) |
| **P14** | GPIO (SPI MISO 겸용) | Port2 신호: 위와 동일 그룹(2번째 신호선), 초음파(Trig) / 디지털튜브(CLK) | 10 | 🔴 사용중(공용) |
| **P15** | GPIO (SPI SCK 겸용) | **온보드 RGB 조명 데이터 라인** | 1 | 🔴 사용중 |
| **P16** | GPIO, 범용 | 코드상 미사용 | — | 🟢 여유 |
| **P19** | I2C SCL (하드웨어 고정) | 컬러센서 / MP3모듈 / ASR모듈 I2C 버스 | 4 | 🔴 사용중(공용버스) |
| **P20** | I2C SDA (하드웨어 고정) | 컬러센서 / MP3모듈 / ASR모듈 I2C 버스 | 4 | 🔴 사용중(공용버스) |
| **3V** | 전원 출력 | 보드 전원 공급 | 5, 9 | — |
| **GND** | 그라운드 | 공통 그라운드 | 전체 | — |

## 요약 — AiHand 프로젝트 관점에서 중요한 핀

### 🚫 절대 건드리면 안 되는 핀 (AiHand 서보 제어 채널)
- **P8** (RX)
- **P12** (TX)

### ⚠️ 확장보드 10번 커넥터가 점유 중인 핀
현재 비어있어도 물리적으로 이 핀들과 연결되어 있음
- **P1, P2, P13, P14**

### ⚠️ I2C 버스 (컬러센서 등과 공유)
- **P19, P20**

### 🟢 완전히 자유로운 핀 (코드/확장보드 모두 미사용)
- **P0, P3, P4, P6, P7, P9, P10, P16**
- 단, **P5(버튼A), P11(버튼B)**는 사용 가능하지만 버튼 기능과 겸용되므로 주의
